# Ялинка — тестування веб-ресурсу онлайн-магазину

Навчальний веб-ресурс на тему «Тестування веб-ресурсу онлайн-реалізації продукції універмагу “Ялинка”». Сайт поєднує вітрину магазину з робочими сценаріями пошуку, фільтрації, керування кошиком, оформлення замовлення та перегляду даних у кабінеті працівника.

## Сценарії для перевірки

- пошук товару та фільтрація за категорією;
- додавання товарів у кошик, зміна кількості та синхронізація підсумку;
- валідація форми й збереження замовлення в SQLite;
- адаптивне відображення сторінок магазину та кабінету.

## Запуск локально

Потрібен Node.js 22 або новіший.

```bash
npm start
```

Сайт буде доступний за адресою `http://localhost:3000`.

Для автоматичного перезапуску під час розробки:

```bash
npm run dev
```

## База даних

SQLite-файл створюється автоматично після першого запуску:

`data/yalynka.sqlite`

Каталог товарів та замовлення зберігаються в БД. Папку `data` потрібно зберегти в персистентному сховищі хостингу.

## Публікація

Проєкт можна розмістити на хостингу з підтримкою Node.js (Render, Railway, VPS або аналогах). Команда запуску: `npm start`. Змінна оточення `PORT` налаштовується хостингом автоматично.
